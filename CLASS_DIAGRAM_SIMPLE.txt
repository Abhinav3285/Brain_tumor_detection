Inheritance:
  UNet ──────────────> torch.nn.Module
  SegmentationDataset ──────────────> torch.utils.data.Dataset

Dependencies (uses):
  StreamlitApp ──────> YOLO, UNet, GradCAMUtils, PredictionUtils
  GradCAMUtils ──────> UNet
  PredictionUtils ────> UNet
  TrainingModule ─────> YOLO, SegmentationDataset

Composition:
  UNet contains:
    - enc1 (Sequential)
    - pool (MaxPool2d)
    - dec1 (Sequential)
  
  SegmentationDataset contains:
    - transform (Compose)
    - images list
    - masks list

Total Components:
  ✓ 2 Core Classes (UNet, SegmentationDataset)
  ✓ 1 External Class (YOLO)
  ✓ 4 Functional Modules (StreamlitApp, GradCAMUtils, PredictionUtils,
                          TrainingModule)

Design Pattern: Modular Architecture with Separation of Concerns

Layers:
  1. Presentation Layer: Streamlit UI
  2. Business Logic Layer: Staging, visualization generators
  3. Model Layer: UNet, YOLO
  4. Data Layer: SegmentationDataset
  5. Utility Layer: Grad-CAM, prediction utilities

Technology Stack:
  • PyTorch: Deep learning framework
  • Ultralytics YOLOv8: Object detection
  • Streamlit: Web application framework
  • OpenCV & NumPy: Image processing

## Legend

```
┌─────────────┐
│   Class     │  = Object-Oriented Class (has __init__, methods)
└─────────────┘

┌─────────────┐
│  «module»   │  = Functional Module (functions only, no class)
└─────────────┘

┌─────────────┐
│ «external» │  = External dependency (not in project)
└─────────────┘

  ──────>  = Inheritance (extends/inherits from)
  ─ ─ ─>  = Dependency (uses)
  ═════>  = Composition (contains)
```
